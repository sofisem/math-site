Задание №12
Наибольшее/наименьшее значение

Исследование функций с помощью производной: точки максимума и минимума, наибольшее и наименьшее значение на отрезке. Погнали! 📈

Твой прогресс: 0 / 0

📖 Теория

Как искать max/min и наибольшее/наименьшее значение?

📈

Главный инструмент — производная. Она показывает, как меняется функция.

1. Точки экстремума (max/min)

  1. Находим производную \(y'\).
  2. Приравниваем к нулю: \(y' = 0\) — это критические точки.
  3. Определяем знак \(y'\) слева и справа от каждой точки.
  4. Если знак меняется с \(+\) на \(−\) — это максимум. С \(−\) на \(+\) — минимум.

2. Наибольшее/наименьшее значение на отрезке \([a; b]\)

  1. Находим \(y'\) и критические точки.
  2. Оставляем только те критические точки, которые лежат внутри отрезка.
  3. Считаем значения функции в этих точках и на концах отрезка \(a\) и \(b\).
  4. Из всех значений выбираем наибольшее/наименьшее.
📝 Пример: \(y = x^3 - 27x + 14\), найти точку максимума.

1. \(y' = 3x^2 - 27 = 3(x^2 - 9) = 3(x-3)(x+3)\).

2. \(y' = 0 \Rightarrow x = 3\) или \(x = -3\).

3. Знаки \(y'\):
\(x < -3\): \(y' > 0\) (возрастает)
\(-3 < x < 3\): \(y' < 0\) (убывает)
\(x > 3\): \(y' > 0\) (возрастает)

4. В точке \(x = -3\) знак меняется с \(+\) на \(−\) — это максимум.

Ответ: \(-3\)

💡

Лайфхак: Если в задаче спрашивают «точку максимума/минимума» — в ответ пишем только \(x\). Если «наибольшее/наименьшее значение» — пишем \(y\).
