Задание №11
Графики функций

Учимся находить параметры функций по графику: прямые, параболы, гиперболы, корни, степени и логарифмы. Погнали! 📈

Твой прогресс: 0 / 0

📖 Теория

Как искать параметры по графику?

🔍

Главный секрет: найди на графике точку с целыми координатами (или несколько), подставь \(x\) и \(y\) в формулу и реши уравнение относительно неизвестного параметра.

1. Линейная \(y = kx + b\)

  • \(b\) — это точка пересечения с осью \(Oy\). Смотрим, где прямая пересекает вертикальную ось.
  • \(k\) — угловой коэффициент (наклон). Берём две точки: \(k = \frac{y_2 - y_1}{x_2 - x_1}\).

2. Парабола \(y = ax^2 + bx + c\)

  • \(c\) — точка пересечения с осью \(Oy\).
  • Если вершина параболы известна, используй формулу \(y = a(x - x_0)^2 + y_0\).
  • Подставь координаты любой другой точки, чтобы найти \(a\).

3. Гипербола \(y = \frac{k}{x}\)

  • Берём любую точку на графике и подставляем: \(k = x \cdot y\).

4. Корень \(y = a\sqrt{x}\)

  • Берём точку с удобным \(x\) (например, \(x=4\) или \(x=9\), чтобы корень извлекался).
  • Подставляем и находим \(a\).

5. Показательная \(y = a^x\) и Логарифмическая \(y = \log_a x\)

  • Для \(y = a^x\): берём точку, подставляем \(x\) и \(y\), решаем \(a^x = y\).
  • Для \(y = \log_a x\): аналогично, \(\log_a x = y \Rightarrow a^y = x\).
